SteamGridDB
API key

That’s all you need. Get a free key at steamgriddb.com → Preferences → API (sign in with Steam), paste it above and press Test connection. The key is stored only in this browser.

Advanced: custom relay

chimiNES reaches SteamGridDB through a small relay, because SteamGridDB doesn’t accept calls straight from web pages. A relay is built in; to use your own instead, deploy the Worker in the repo’s steamgriddb-proxy folder and paste its URL here. Leave empty to use the built-in one.
